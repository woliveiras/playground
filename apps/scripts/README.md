# TypeScript Script Examples

This directory contains simple TypeScript scripts that can be executed directly using `ts-node`.

## How to Run

1. Install dependencies:

   ```bash
   pnpm install
   ```

2. Run the example script:

   ```bash
   pnpm --filter scripts dev
   ```

3. To run a specific script, use the `runner.js` file. For example, to run `hello-world.ts`:

   ```bash
   pnpm --filter scripts start hello-world 
   ```
